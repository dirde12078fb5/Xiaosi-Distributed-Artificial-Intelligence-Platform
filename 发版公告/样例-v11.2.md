# v11.2 Pro Max X3D 发布 —— 多线程下载再提速,新增小思超级 PXE 网络安装模块

**小思分布式人工智能平台**:把散落桌面的开发运维工具,收进一个不卡顿的窗口。

![封面图](https://raw.gitcode.com/user-images/assets/9293520/1388b96f-1785-4ea7-943a-9302716842dc/7月23日.gif)

## 🎯 本次更新亮点

- 🚀 下载器重构,8 线程分块 + 断点续传更稳,大文件提速约 40%
- 🧩 新增「小思超级 PXE」跨平台网络安装模块(DHCP/TFTP/HTTP,纯 Python 标准库,零依赖)
- 🔧 修复 Windows 11 24H2 下 GPU 深度检测闪退问题
- 🎨 工具箱网格 UI 细节统一,深色模式配色更协调

## ✨ 新功能

- **小思超级 PXE**:跨平台网络安装系统,含 GUI,支持网络启动安装操作系统,Windows/Linux/macOS 通用
- **小思超级多版本 NAS**:Go 实现的多版本 NAS 服务首版合入,支持 SMB 与多语言(i18n)配置

## 🔧 改进

- 多线程下载器:分块策略优化,断点续传校验更严格
- 硬件检测:CPU 缓存信息读取更准,兼容更多型号
- 一键搭建脚本:`快速搭建/` 新增 `.bat` + `.sh`,Windows 双击即可装依赖、选单启动

## 🐛 修复

- 修复 Win11 24H2 下 NVML 调用偶发闪退
- 修复网络模块 WiFi 扫描在部分网卡下结果为空
- 修复视觉模块 OpenCV 在无摄像头时崩溃
