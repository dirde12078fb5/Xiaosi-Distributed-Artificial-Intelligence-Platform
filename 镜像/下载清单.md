# 系统镜像清单与获取方式

> 本仓库**不再托管系统镜像等大体积二进制文件**，镜像一律在本地保留、按需自行获取。
>
> 原因：gitcode 的 Git LFS 存在硬性限制 —— 单文件约 2.5 GB 以上会返回 HTTP 502/413，仓库 LFS 总配额 2.0 GiB，
> 而镜像目录合计约 160 GB，客观上无法完整入库。相关忽略规则见仓库根目录 `.gitignore`。

## 二、分卷合并方法

Windows（需 7-Zip）：

```powershell
# 只需定位到 .001，7-Zip 会自动串联后续分卷
& "C:\Program Files\7-Zip\7z.exe" x "cn_windows_8_x64_dvd_915407.iso.7z.001" -o.
```

Linux / macOS：

```bash
# 方式一：按顺序拼接即可（store 模式，无压缩头）
cat xxx.iso.7z.00? > xxx.iso

# 方式二：用 7z 自动识别
7z x xxx.iso.7z.001
```

## 五、仓库体积约束备忘

- LFS 单文件安全上限：**2.5 GB**（超出易触发 502 / 413）
- LFS 仓库配额：**2.0 GiB**（当前仓库远超，push 会持续出现超限警告）
- 结论：镜像类资产一律本地留存 + 官方源下载，不入库、不传输。
